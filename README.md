# PG Staff Schedule

AI-powered employee scheduling PWA for field use.

**Live:** https://apphub-us.github.io/pg-staff-schedule/

## Features
- Weekly schedule grid with shift cycling
- AI assistant for substitution suggestions (uses Claude API)
- Statistics view with workload analysis
- PWA — add to iPhone home screen
- Offline support via Service Worker
- Data saved locally on device

## Shifts
- **M** — Morning 6:00–14:00
- **A** — Afternoon 14:00–22:00
- **N** — Night 22:00–06:00
- **W** — Day off
- **CH** — Sick leave

## Add to iPhone
1. Open in Safari: https://apphub-us.github.io/pg-staff-schedule/
2. Tap Share → "Add to Home Screen"
3. Works offline after first load
